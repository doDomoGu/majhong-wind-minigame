# 立直麻将 · 风向盘

四人各自打开、同步看分的立直麻将计分小游戏，规则大体按 M.League。需求草案见：

- [项目概要.md](./项目概要.md)
- [功能需求.md](./功能需求.md)
- [用户流程.md](./用户流程.md)
- [云开发.md](./云开发.md)

大厅已可操作。四人同步走[微信云开发](./云开发.md)；未配置环境时，浏览器预览仍用本机房间。

## 源码目录

```
├── cloudfunctions             // 云函数 login / room
├── js                         // 客户端
├── game.js                    // 入口
├── game.json
├── preview.html               // 浏览器画面预览
├── 云开发.md                  // 开通与部署步骤
└── project.config.json
```

## 如何预览

- **四人同房**：微信开发者工具打开本目录，按 [云开发.md](./云开发.md) 开通环境、部署云函数。
- **只看画面**：打开 `preview.html`，不连云。
